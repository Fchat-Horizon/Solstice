Built on Horizon 2.5.0-beta.0.

A test build of Horizon's 2.5 beta, where all settings move into one menu and chat settings are shared by every character.

## Changes since v2026.10.0

- **One settings menu.** App settings and chat settings now live in the same menu, opened from the gear in chat. On a phone the sections are in a dropdown at the top, and options that only make sense on desktop are hidden.
- **Settings shared across characters.** Chat settings are now global, and any character can override them from its own tab in the menu. The first time you connect after updating, Solstice asks whether to keep that character's settings as the global ones or start fresh. Please try both.
- **Colourblind modes and high contrast.** Colourblind mode now offers a choice of types and moved to App > Accessibility, next to a new high-contrast mode. Reduced motion, vanilla colours and BBCode glow now take effect on phones too.
- **Per-character themes.** A theme set for one character (Appearance > Page layout) now applies while that character is connected.
- **Logging channels.** Channel messages can be logged or not separately from private messages.
- **Reconnecting.** After a dropped connection Solstice keeps trying instead of giving up, and logging in reuses one login ticket instead of asking F-List for a new one on every connect.
- **Commands with leading spaces.** Sending " /me waves" with spaces in front now warns that it will go out as plain text, and sends it as typed if you send it again.
- **Chat box.** On a phone the formatting buttons sit behind an Aa button, and the character counter is hidden.
- **Eicon picker.** Searching works when the keyboard adds a space after a suggestion, an eicon uploaded minutes ago can be sent by typing its full name, and the picker no longer gets stuck on its loading spinner.
- **Message drafts.** Text you typed but did not send is saved when the app goes to the background and is still there after a restart.
- **Side drawers.** An open drawer reaches the screen edges instead of leaving a darkened strip around it on light themes.
- **Hidden characters' ads.** Ads from characters you have hidden no longer show in channels.
- **Translations.** Japanese is now fully translated, with updates to Spanish, French, Hungarian and Italian.
